# คู่มือใช้งาน — โปรแกรมตรวจสีไฟ LED

ตรวจว่าไฟ LED ดวงไหน "เพี้ยน (ออกฟ้า/เหลือง)" ผ่านกล้อง โดยดูจากหน้าเว็บ
**ไม่ต้องพิมพ์คำสั่งอะไรตอนใช้งาน** — เปิดโปรแกรมครั้งเดียว ที่เหลือคลิกบนเว็บ

---

## ใช้งานประจำวัน (หลังติดตั้งเสร็จแล้ว)

1. **เปิดโปรแกรม** (ดูหัวข้อ "เปิดโปรแกรม" ตาม OS ด้านล่าง) — จะเปิดหน้าเว็บให้เอง
   ถ้าไม่เปิด ให้เปิดเบราว์เซอร์ไปที่ **http://localhost:8000**
2. **เลือกกล้อง** — กดปุ่ม **📷 เลือกกล้อง** จะเห็นภาพเล็กๆ ของกล้องแต่ละตัว
   **คลิกภาพที่เห็นไฟ LED** (ไม่ต้องรู้ว่ากล้องตัวไหน index เท่าไร)
3. **ดูภาพ** — ควรเห็นแต่ดวงไฟสว่างบนพื้นมืด (โปรแกรมลดแสงให้อัตโนมัติแล้ว)
   ถ้ายังสว่างฟุ้งเป็นปื้นขาว → กดปุ่ม **มืดลง**  
   **ถ้าภาพกลับด้าน / สลับซ้ายขวาบนล่าง** → กดปุ่ม **🔄 กลับภาพกล้อง** (แกน X / แกน Y) เพื่อกลับภาพ (ระบบจำให้อัตโนมัติ)
4. **วางชิ้นงาน** เรียงเป็นแถวแนวนอนให้เข้าในกรอบภาพ
5. **กรอกจำนวน** "จำนวนชิ้น" และ "ดวงต่อชิ้น" แล้วกด **▶ เริ่มตรวจ**
   (รวมทุกดวงไม่เกิน 10 ดวงต่อรอบ)
6. **อ่านผล** ทางขวา:
   - **✅ OK** = ผ่านทุกชิ้น
   - **❌ NG** = มีชิ้นเพี้ยน (บอกว่าชิ้นไหน + ฟ้า/เหลือง)
   - **⏳ ไม่ครบ** = หาดวงไฟบางดวงไม่เจอ (ขยับชิ้นงาน/เพิ่มแสงดวงนั้น)
   - ดวงที่หาไม่เจอจะขึ้น **"ไม่พบ"** ในตาราง ส่วนดวงอื่นยังตรวจได้ตามปกติ

### โหมดแม่นยำ (ถ้าใช้ได้): Calibrate ขาวอ้างอิง
ตรวจฟ้า **และ** เหลืองได้แม่นกว่าโหมดปกติ — แต่ต้องตั้งให้ถูกลำดับ:
1. ล็อกแสงก่อน (ปุ่มล็อกแสง) แล้ว **อย่าเปลี่ยนค่าแสงอีก**
2. วาง **ชิ้นดีล้วนๆ** ให้ครบทุกจุด → กด **▶ เริ่มตรวจ**
3. กด **🎯 Calibrate ขาว** (ระบบจำค่าขาวไว้ถาวร)
4. ค่อยสลับเอาชิ้นที่จะเทสเข้ามา
> ถ้าตอน calibrate มีชิ้นเพี้ยนปนอยู่ ระบบจะ **ปฏิเสธ** และบอกให้เอาออกก่อน
> กด **ล้างอ้างอิง** เพื่อกลับโหมดเทียบกันเอง

### นาฬิกาจับเวลา
ด้านล่างมีนาฬิกานับถอยหลัง ตั้งเวลาแล้วกดเริ่ม ครบเวลาจะกะพริบแดง + มีเสียงเตือน

## ติดตั้งครั้งแรก (ทำครั้งเดียวต่อเครื่อง)

ต้องมี **Python 3.10+** ก่อน (ดาวน์โหลดที่ python.org) แล้วเปิด terminal/command prompt
ไปที่โฟลเดอร์โปรแกรมนี้ แล้วทำตาม OS:

### macOS / Linux
```bash
python3 -m venv .venv
./.venv/bin/pip install -r requirements.txt
```
**เปิดโปรแกรม:**
```bash
./.venv/bin/python webapp.py
```

### Windows
```bat
py -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```
**เปิดโปรแกรม:** ดับเบิลคลิก **`run_windows.bat`** หรือสั่ง:
```bat
.venv\Scripts\python webapp.py
```

## หมายเหตุ deploy / แก้ปัญหา

- **ให้เครื่องอื่นใน LAN เปิดดูได้** (เช่นมือถือหน้าไลน์ผลิต): เปิดด้วย
  `webapp.py --host 0.0.0.0` แล้วเข้าจากเครื่องอื่นที่ `http://<ไอพีเครื่องนี้>:8000`
  (ภาพ+ปุ่มควบคุมจะเปิดให้ทั้งวงโดยไม่มีรหัส — ใช้เฉพาะวงในที่ไว้ใจได้)
- **กล้องต้องเสียบกับเครื่องที่รันโปรแกรม**
- **ล็อกแสงตาม OS:**
  - mac = ใช้ `tools/uvc-util` ที่มากับโปรแกรม (เสถียรสุดกับกล้อง Anker C200)
  - Windows/Linux = สั่งผ่าน OpenCV (best-effort) บางกล้องตั้งไม่ได้
  - **ถ้ากล้องตั้งแสงไม่ได้** → กด "แสงอัตโนมัติ" แล้ว **จัดห้องให้มืดลง**
    ให้เห็นแต่ดวงไฟแทน (ผลลัพธ์เหมือนกัน)
  - ⚠️ **สำคัญมากบน Windows/Linux ที่ล็อกแสงไม่ได้:** ถ้าห้องสว่าง โปรแกรมอาจ
    จับแสงสะท้อน/พื้นหลังเป็น "ดวง" ผิดได้ → **ต้องจัดให้พื้นหลังมืด เห็นแต่ดวงไฟชัดๆ
    ก่อนกดเริ่มตรวจเสมอ** (บน mac ที่ล็อกแสงได้ไม่ต้องห่วงข้อนี้)
- **กล้อง index สลับเอง / เปิดไม่ติด** → กดปุ่ม "📷 เลือกกล้อง" แล้วคลิกตัวที่เห็นไฟ LED
  ระบบจะจำกล้องที่เลือกไว้ (ใน `config.json`) ครั้งหน้าเปิดมาใช้ตัวเดิม
- **กล้องดับเองตอนไม่ใช้** เป็นเรื่องปกติ (ประหยัดแบต) — ทิ้งหน้าเว็บไว้ไม่ดูเกิน 1 นาที
  กล้องจะปล่อย พอเปิดดูใหม่จะกลับมาเอง
- **ออปชันตอนเปิด:** `--cam N` เลือกกล้องตรงๆ, `--exposure 0` ปล่อย auto ไม่ล็อกแสง,
  `--port 9000` เปลี่ยนพอร์ต
